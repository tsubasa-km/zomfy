# Bot sources

* [Discord source](discord.md) - mention, DM or slash command in Discord, threads, buttons, through one Discord application per deployment
* [Slack source](slack.md) - mention or DM in Slack, thread replies, Block Kit questions, approvals, Stop and status edits, one Slack app per deployment
* [GitHub source](github.md) - mentions on issues and PRs through the person's own GitHub App, replies, review notes, PR events and triggers
* [Linear source](linear.md) - mention or bot label on a Linear issue, replies with an asked-by line, Linear triggers
* [Webhook source](webhooks.md) - a keyed URL per hook that starts a bot run, with signatures, filters, redaction, caps and retention
